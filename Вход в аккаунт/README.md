# Pit Stop Rush — экран входа

Первый этап карьеры: самостоятельная демонстрация экрана входа по концепт-арту. Поля и кнопки интерактивны, однако авторизация, регистрация и гостевой вход пока не подключены. Пароли никуда не отправляются и не сохраняются.

Для локального запуска из этой папки: `python -m http.server 8000 --directory dist`, затем открыть `http://localhost:8000`.

`dist/` содержит сайт и необходимые изображения и шрифт. Каждому последующему этапу игры предназначается отдельная папка.
