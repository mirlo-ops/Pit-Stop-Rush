# Pit Stop Rush — браузерная версия

Браузерная версия на JavaScript и Phaser. Исходная игра находится в соседней папке `игра на Python`.

Для каждого колеса первое нажатие открывает крупный план с гайкой. Удерживайте её, чтобы открутить; следующее нажатие на колесо открывает закручивание. Каждое действие занимает 0,675 секунды удержания, а таймер пит-стопа продолжает идти. Если гайковёрт заест, выполните QTE и продолжите удержание. Золото — до 15,00 с, серебро — до 20,00 с, бронза — свыше 20,00 с.

Из этой папки запустите `python -m http.server 8000 --directory dist` и откройте `http://localhost:8000`. Доступ к сети нужен для Firebase; без него результаты остаются в хранилище браузера. Для переноса прогресса со старого устройства требуется отдельная функция: браузер и Python используют разные локальные хранилища.

Файлы `dist/` содержат готовую статическую версию, включая Phaser и игровые ресурсы. Клиент использует гостевую авторизацию Firebase и Realtime Database напрямую; адрес базы и Web API Key находятся в `dist/firebase-config.json`. В Firebase должны быть включены анонимный вход и правила чтения и записи рейтингов.

Общий рекорд хранится в `leaderboards/global/<uid>`, ежедневный — в `leaderboards/daily/<дата UTC>/<uid>`. При повторной отправке результат заменяет существующий только если он лучше. Очередь сохраняется в браузере и повторяется после восстановления сети. Гостевой профиль привязан к браузеру: очистка его данных может привести к потере доступа к профилю. Рейтинги в интерфейсе обновляются при открытии и периодически во время игры.

Имя пилота меняется кнопкой в правой верхней части главного меню и хранится в браузере. После подключения новое имя обновляется в общем рейтинге, в рейтинге текущего дня и в ежедневных рейтингах, даты которых этот браузер сохранил после добавления функции. Время и медали не меняются. При отсутствии сети имя синхронизируется после восстановления соединения; старые ежедневные результаты за неизвестные браузеру даты не переименовываются.

После сброса рейтингов используется версия правил `2`: старые записи из очереди сохраняются в `pitstop.web.legacy-pending` и не отправляются повторно. Локальный рекорд нового сезона хранится отдельно от прежнего. Realtime Database принимает только результаты с полем `version: 2`.

Музыкальная тема используется из исходного проекта; перед публичным распространением проверьте право на её использование.
